# Application integrations

Future game adapters belong here or in the game's own repository. An adapter
may depend on both game code and public Hetoimasia interfaces. Engine libraries
must not import adapters. No Synarchy source or assets have been copied here;
the Ecce Homo content rebuilt so far, including terrain artwork copied byte for
byte from Synarchy with its provenance, is in
[samples/ecce-homo](../samples/ecce-homo/README.md).
