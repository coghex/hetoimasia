# Technical PNG fixtures of the `Lua offscreen pixels` group (LFE-24)

**These are technical test assets, not production art.** They exist so the pixel cases of
`lua-engine-graphics-native-tests` (and the device-free comparator cases of `lua-engine-graphics-tests`) can tell a wrong
Lua translation, a wrong decoder and a wrong renderer apart by contrast. None is approved art; none is a placeholder for
art.

Each is a small RGBA8 static PNG written by [`generate_pixel_fixtures.py`](generate_pixel_fixtures.py) with the standard
library only: filter type 0 on every scanline, one IDAT chunk compressed at zlib level 9, no ancillary chunk. The bytes
are a pure function of that file (re-running the script reproduces them exactly), and the script's texel tables are the
*source* of the images. The suites state the same tables again, by hand, in `Test.LuaEngine.Graphics.Pixels`, and check
the committed files against them, against the SHA-256 below and against what the production decoder reads back; neither
side is derived from the other, from the decoder under test or from any captured framebuffer.
