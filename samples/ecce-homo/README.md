# Ecce Homo content (terrain arena)

Authored content the terrain arena's later assembly (TRA-11) consumes. Nothing
here is engine library source and no engine library depends on it.

- `content/textures/loam.png`, `content/textures/granite.png` — the approved
  artwork, 96 × 64, copied byte for byte from Synarchy; see
  `content/textures/provenance.json` for the source revision and path, the
  destination, dimensions and SHA-256, and the mapping from Synarchy's
  `mat_tile_56` / `mat_tile_1`. A CPU test recomputes each hash and dimension.
