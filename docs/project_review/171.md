## 1. Qualification provenance

### PRR-1. Bound the toolchain evidence freshness claim to the revision it establishes

> **Captured note:** P3 — Replace the evidence index's unbounded assertion that
> every commit after `be92703` changes only documentation and that its diff to
> `HEAD` must be empty outside `docs/`. The PR's own final base merge already
> invalidated that assertion. Preserve the receipts' true execution revision
> and describe any later validation separately.

**Verification:** The assertion is still present at the verification pin.
Comparing the qualification revision to reviewed PR head `cb5fb381` gives no
non-documentation changes. Comparing it to final PR head `057d59aa`, or to
merge commit `3af4cb2d`, gives five GLFW implementation/test paths. These
changes arrived in the PR's last commit, which merged `master` after the final
review. The index therefore shipped a check whose documented expected result
was already false, independently of the subsequent Lua and Vulkan work.

The artifacts themselves consistently retain their actual execution revision;
this does not establish that they were mislabeled or that the selected compiler
ceased to qualify. It establishes that the index's current-evidence claim and
its proposed verification boundary are incorrect.

**Evidence:**

- `docs/toolchain/README.md:16` correctly identifies `be92703` as the artifacts'
  execution revision. Lines 21–24 then say all later commits only add/correct
  documentation and change no qualified input.
- `docs/toolchain/README.md:27` checks the unbounded range
  `git diff be92703..HEAD --name-only | grep -v '^docs/'`. Lines 30–32 say it
  should print nothing and require re-execution if any path appears.
- `docs/toolchain/receipts-darwin/test.glfw.json:11` records execution at
  `be927031a18dec744acc35a162c0fa6af74c4e75`, before the final base merge's
  GLFW implementation and test changes.
- PR #171's final commit `057d59aa2d6c9223ea6608221281172a73ac7f77` is
  “Merge branch 'master' into issue-157-qualify-toolchain”; the PR merged as
