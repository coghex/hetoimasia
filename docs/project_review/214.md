## 1. Readiness-process ownership

### [#372] PRR-1. [P2] Stop and reap the active readiness client when startup is signalled

> **Captured note:** The Wayland helper's signal cleanup forgets the readiness process it started. Retain the obligation to stop and reap an in-flight client when startup exits through a catchable signal, as well as when its readiness budget expires normally.

**Verification:** A fresh coordinated Hspec witness ran the actual pinned `tools/display/wayland.sh` under Bash 3.2 and 5.3. A private compositor stub recorded its PID/runtime and waited; a readiness-client stub recorded its PID, signalled the helper through its helper-generated socket name, then waited on a fixture-owned FIFO. The helper returned `143`, reported SIGTERM, stopped/reaped the compositor, removed the runtime and never started the command. In both cases the recorded readiness client was still alive after the helper returned. The witness's `finally` then stopped its own recorded processes and asserted their disappearance; a subsequent process check also found both readiness PIDs absent. Two examples passed in 0.2666 seconds because their explicit oracle asserts the observed defect; these are not green regression tests of correct cleanup.

```text
Bash 3.2: helper_exit=143 compositor_gone=True runtime_gone=True command_ran=False active_probe_survived=True
Bash 5.3: helper_exit=143 compositor_gone=True runtime_gone=True command_ran=False active_probe_survived=True
2 examples, 0 failures
```

The client's wait is an explicitly coordinated fixture barrier, and the helper return has a three-second witness bound; the production ten-second readiness deadline is not exercised. Neither stub initializes a display or uses a real Wayland connection.

**Evidence:**

- `tools/display/wayland.sh:156` — `probe` starts `wayland-info` and retains its PID only in local `prober`. Its own kill/wait at lines 168–169 is reached on normal budget exhaustion.
- `tools/display/wayland.sh:108` — the TERM/INT/HUP handler exits after stopping only `command_pid`; during startup it is empty. Exiting here unwinds the still-running `probe` before its own cleanup.
- `tools/display/wayland.sh:92` — the EXIT handler stops/waits only `compositor` and removes scratch. It neither stops nor waits for the readiness client.
- `tools/wayland-test/Main.hs:190` — the committed startup-signal example exercises a client that sends TERM and immediately exits; `signallingClient` ends with `exit 1` at line 332. It does not keep a readiness operation in flight across the helper's exit.
- `tools/wayland-test/Main.hs:339` — `cleanedUp` inspects the compositor and directories, without asserting readiness-process retirement.
- The merged helper introduced this same local-prober and signal-handler sequence; later consent/header changes preserve it in the current pinned tree.

**Handoff context:**

- **Current behavior:** A startup signal exits the helper without reclaiming its own active readiness client. The compositor and runtime can be gone while that client remains alive, outside the helper's normal readiness budget and without a parent waiting for it.
- **Expected behavior:** Every helper-owned readiness process is stopped and reaped before startup cleanup completes, including a catchable signal during a connection attempt. Preserve status `128+N`, the command-not-started guarantee, isolation, normal readiness results and the readiness budget.
- **Scope and constraints:** This is the production display helper's direct-child ownership, not a test fixture's escaped descendant or a native backend defect. Touch only helper-owned processes. Keep real deadline experiments optional; a fast coordinated failure-path check can prove this boundary without running a compositor or waiting out a deadline.
- **Verification target:** Park a client after its launch, signal the helper while that attempt remains active, and prove helper status, no command execution, compositor/client absence and runtime removal before returning. Cover TERM and the common INT/HUP handler, and retain successful startup and normal refusal coverage. Ensure assertion failure/cancellation cannot abandon the regression fixture's own children.
- **Deduplication:** Fresh complete open-issue inventory and all-state searches for Wayland readiness, readiness client and compositor cleanup found no issue specifically tracking this obligation. Open #202 is the broader qualification epic; closed #204/#207 specify provisioning/qualification, not a correction of this path. The claim-held #214 row has no earlier report or history, so this is a new entry rather than an own-row repeat. Reports #240/#236 concern fixture-owned X11 FIFO writers; #278/#356 concern child-launcher output reader threads; #260 concerns validation descendants in separate process groups. Those are distinct owners and defects.
- **Remaining uncertainty:** The witness proves the helper fails to reclaim an active client; it does not establish how long the real `wayland-info` would remain alive after a real compositor closes its connection. No current native Wayland hang, real-client leak duration, Linux image execution or whole optional-suite outcome is claimed.

## Reproduction source

Save the Hspec source below outside the pinned checkout. Compile with the repository-qualified GHC and Hspec package environment, then pass the pinned checkout and an empty scratch directory as its two arguments. It uses only local stubs and removes its own recorded processes in `finally`.

```bash
ghc -XGHC2024 -XUnicodeSyntax -Wall -Werror -threaded -package hspec ProbeWitness.hs -o probe-witness
./probe-witness /path/to/pinned-checkout /path/to/empty-scratch
```

```haskell
{-# LANGUAGE UnicodeSyntax #-}
module Main (main) where
import Control.Concurrent (yield)
import Control.Exception (IOException, finally, try)
import Control.Monad (forM_, void)
import System.Directory (createDirectoryIfMissing, doesDirectoryExist, doesFileExist, getPermissions, setOwnerExecutable, setPermissions)
import System.Environment (getArgs, getEnvironment, withArgs)
import System.Exit (ExitCode(..))
import System.FilePath ((</>))
import System.IO (IOMode(WriteMode), withFile)
import System.Posix.Signals (nullSignal, sigKILL, signalProcess)
import System.Process (CreateProcess(..), StdStream(UseHandle), callProcess, proc, terminateProcess, waitForProcess, withCreateProcess)
import System.Timeout (timeout)
import Test.Hspec
import Test.Hspec.Runner (Config(configFailOnEmpty), defaultConfig, hspecWith)
main ∷ IO ()
main = do
  [tree, scratch] ← getArgs
  withArgs [] $ hspecWith defaultConfig {configFailOnEmpty=True} $
    forM_ [("/bin/bash","bash32"),("/opt/homebrew/bin/bash","bash53")] $ \(bash,label) →
      it ("keeps an active readiness client after startup SIGTERM under "++label) $
        witness tree (scratch </> label) bash
alive ∷ Int → IO Bool
alive pid = do
  result ← try (signalProcess nullSignal (fromIntegral pid)) ∷ IO (Either IOException ())
  pure (either (const False) (const True) result)
pidAt ∷ FilePath → IO (Maybe Int)
pidAt path = do
  exists ← doesFileExist path
  if exists then Just . read <$> readFile path else pure Nothing
cleanup ∷ FilePath → IO ()
cleanup scratch = forM_ ["probe.pid","compositor.pid"] $ \name → do
  candidate ← pidAt (scratch </> name)
  forM_ candidate $ \pid → do
    running ← alive pid
    if running then void (try (signalProcess sigKILL (fromIntegral pid)) ∷ IO (Either IOException ())) else pure ()
    gone ← timeout 2000000 (let wait = alive pid >>= \still → if still then yield >> wait else pure () in wait)
    shouldBe gone (Just ())
writeExecutable ∷ FilePath → String → IO ()
writeExecutable path contents = do
  writeFile path contents
  permissions ← getPermissions path
  setPermissions path (setOwnerExecutable True permissions)
witness ∷ FilePath → FilePath → FilePath → IO ()
witness tree scratch bash = do
  createDirectoryIfMissing True (scratch </> "bin")
  callProcess "/usr/bin/mkfifo" [scratch </> "release"]
  let box = scratch </> "bin"
  writeExecutable (box </> "weston") $
    unlines ["#!/bin/sh","case \"$1\" in --version) echo 'weston 13.0.0'; exit 0;; esac",
      "echo $$ > compositor.pid","echo \"$XDG_RUNTIME_DIR\" > runtime.txt","exec /bin/sleep 30"]
  writeExecutable (box </> "wayland-info") $
    unlines ["#!/bin/sh","echo $$ > probe.pid","kill -TERM \"${WAYLAND_DISPLAY#hetoimasia-}\"",
      "read -r released < release","echo released > probe-finished"]
  inherited ← getEnvironment
  let overrides = [("PATH",box++":/usr/bin:/bin"),("TMPDIR",scratch)]
      settings = overrides ++ filter (\(name,_) → notElem name (map fst overrides)) inherited
  finally
    (withFile (scratch </> "output") WriteMode $ \output →
      withFile (scratch </> "errors") WriteMode $ \errors →
        withCreateProcess (proc bash [tree </> "tools/display/wayland.sh","--","/bin/sh","-c","touch command-ran"])
          {cwd=Just scratch,env=Just settings,std_out=UseHandle output,std_err=UseHandle errors} $
          \_ _ _ process → do
            ended ← timeout 3000000 (waitForProcess process)
            case ended of
              Nothing → terminateProcess process >> expectationFailure "helper did not return within the witness bound"
              Just result → do
                shouldBe result (ExitFailure 143)
                readFile (scratch </> "errors") >>= \text → shouldContain text "terminated by SIGTERM"
                shouldReturn (doesFileExist (scratch </> "command-ran")) False
                runtime ← takeWhile (/='\n') <$> readFile (scratch </> "runtime.txt")
                shouldReturn (doesDirectoryExist runtime) False
                compositor ← pidAt (scratch </> "compositor.pid")
                forM_ compositor $ \pid → shouldReturn (alive pid) False
                prober ← pidAt (scratch </> "probe.pid")
                case prober of
                  Nothing → expectationFailure "readiness client was not entered"
                  Just pid → do
                    shouldReturn (alive pid) True
                    putStrLn ("helper_exit=143 compositor_gone=True runtime_gone=True command_ran=False active_probe_survived=True pid="++show pid)
    )
    (cleanup scratch)
```
